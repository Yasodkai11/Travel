# TravelHarbor Hub is Live! 🌍✈️
I’ve been working on a travel booking system that brings together trains, hotels, packages, and budget planning into one clean and user-friendly experience and I’m excited to finally share it!
TravelHarbor Hub is designed with a focus on real-world usability and scalable architecture, making it ready for seamless backend integration.

## 🔍 What you can do in this system:
• Search and explore flights, hotels, and travel packages
• Book and manage trips through a structured dashboard
• Cancel bookings with simple workflows
• Plan your expenses using a built-in Trip Budget Planner

## ⚙️ Built With:
React + TypeScript | Tailwind CSS | FastAPI | MySQL | Django
